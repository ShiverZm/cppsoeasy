# 贪心算法的要素
## 一、两个理论前提
要素	含义	本质
贪心选择性质	每一步的局部最优选择，最终能导向全局最优	决定"能不能贪"
最优子结构	做出选择后，剩下的是同类的更小问题，其最优解与已做选择合并后仍是全局最优	决定"能不能递归缩小问题"

最优子结构 DP 也有，贪心选择性质才是贪心独有的：DP 靠比较所有选择，贪心则断言"这一个选择一定不亏"。

## 二、解题的四个要素
### 1. 贪心策略（按什么标准选）

每一步以什么为准？常见标准：

标准	典型题
最大 / 最小	分发饼干（小饼干喂小胃口）
最早结束	无重叠区间、活动选择
最远可达	跳跃游戏
正收益累加	买卖股票 II
成对优先	最长回文串

找策略的方法：问自己"当前有哪些选择？哪个选择会给后面留下最多余地、或者最不可能让后面变差？"

### 2. 处理顺序（往往需要排序）

策略要生效，常常要先排序，使"当前最优"有明确定义：

区间题：按右端点（或左端点）排序
分配题：两边都排序后双指针
无需排序的：一趟扫描维护最值（最远位置、最低价）
### 3. 正确性验证（最关键）

策略想出来不代表对，必须验证：

构造反例：用小数据（n = 3、4）手动试，找不到反例才继续。
交换论证：假设存在最优解没用贪心选择，把它那一步换成贪心选择，结果不变差 → 贪心选择可以出现在某个最优解里。
归纳法：证明贪心每一步都"不落后于"任何其他方案。

反面教材：零钱兑换面值 [1,3,4] 凑 6，"先拿最大面值"有反例，所以不能贪。

### 4. 实现与终止条件
形式通常是：排序 + 一趟循环，或一趟循环维护变量，或优先队列每次取最优。
明确：何时选、何时跳过、如何更新状态（如更新 end、far、剩余容量）。
边界：空输入、单元素、全相同、全负数等。

## 四、与 DP 要素的对比
	DP	贪心
核心要素	状态定义、转移方程、初始化、遍历顺序、返回值	贪心策略、处理顺序、正确性证明、实现
如何决策	比较所有子问题，取最优	直接选定一个，不回头
难点	状态设计	证明策略正确
出错表现	初始化、边界写错	策略本身错（有反例）

## 五、做题时的思考流程
1. 看题目：求最大/最小/最多/最少，且选择有"顺序"或"优先级"？
2. 猜策略：最大？最小？最早？最远？
3. 找反例：用 3~4 个元素的小数据试，能推翻就换策略或改用 DP
4. 说理由：能用一句话讲出"为什么这样选不会亏"（交换论证）
5. 写代码：排序（如需要）+ 一趟扫描
6. 验证边界：空、单元素、全相同、极端值
