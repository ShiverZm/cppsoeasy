# 有效括号

https://leetcode.cn/problems/valid-parentheses/description/

给定一个只包括 '('，')'，'{'，'}'，'['，']' 的字符串 s ，判断字符串是否有效。

有效字符串需满足：

左括号必须用相同类型的右括号闭合。
左括号必须以正确的顺序闭合。
每个右括号都有一个对应的相同类型的左括号。

# 示例
示例 1：

输入：s = "()"

输出：true

示例 2：

输入：s = "()[]{}"

输出：true

示例 3：

输入：s = "(]"

输出：false

示例 4：

输入：s = "([])"

输出：true

示例 5：

输入：s = "([)]"

输出：false

 

提示：

1 <= s.length <= 104
s 仅由括号 '()[]{}' 组成

# 解法
>思路：用左括号都进栈，遇到右括号则和栈顶对比，相对应则出栈，直到栈为空则说明有效；不对应则无效； 

```cpp
class Solution {
public:
    bool isValid(string s) {
        std::vector <char> vect;
        if (s.size() % 2 == 1){
            return false;
        }
        for(int i = 0; i< s.size();i++){
            if(s[i] == '(' || s[i] == '[' || s[i] == '{'){
                vect.push_back(s[i]);
                continue;
            }

            // 到这里一定是右括号：栈空，或栈顶不匹配，都不合法
            if (vect.empty()) return false;
            
            char t = vect.back();
            char c = s[i];
            if ((c == ')' && t != '(') ||
                (c == ']' && t != '[') ||
                (c == '}' && t != '{')) {
                return false;
            }
            vect.pop_back();
        }
        return vect.empty();
    }
};
```
