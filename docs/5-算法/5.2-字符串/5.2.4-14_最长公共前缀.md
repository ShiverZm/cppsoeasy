# 最长公共前缀

# 解法

## 方法1
> 思路:横向对比，一个字符串一个字符串对比 一个个字符，然后最长的公共字符串长度中，取最小的
```cpp
class Solution {
public:
    string longestCommonPrefix(vector<string>& strs) {
        int max_len = 200;
        for(int i = 0; i< strs.size(); i++){
            if(i+1 < strs.size()){
                int temp = 0;
                for(int j = 0; j < strs[i].size(); j++){
                 if(strs[i][j] == strs[i+1][j]){
                    temp++;
                    continue;
                } else {
                    break;
                }
                }

                max_len = min(temp, max_len);
            }
            
        }

        return strs[0].substr(0, max_len);
    }
};
```
