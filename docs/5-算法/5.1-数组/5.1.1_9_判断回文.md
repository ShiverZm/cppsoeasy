# 判断回文数字
https://leetcode.cn/problems/palindrome-number/description/

# 方法
## 方法1
> 思路：判断前半段和后判断是否存在一个数不对称，存在则不是回文
时间复杂度: O(logn)
空间复杂度：O(logn)
```cpp
class Solution {
public:
    bool isPalindrome(int x) {
        if(x < 0) return false;
        if(x == 0) return true;
        std::vector<int> vec;
        int tmp = x;
        while (tmp){
            vec.push_back(tmp % 10);
            tmp = tmp / 10;
        }
        int len = vec.size();
        for(int i = 0; i < len / 2; i++){
            if(vec[i] != vec[len - i -1]){
                return false;
            }
        }

        return true;
    }
};
```

## 方法2
>思路：只反转后半部分，然后与前半部分比较。这样既不需要额外空间，也完全避免了反转整个数时的 int 溢出问题。
时间复杂度: O(logn)
空间复杂度：O(1)
```cpp
class Solution {
public:
    bool isPalindrome(int x) {
        // 负数不是回文；个位是 0 的非零数，反转后首位是 0，不可能相等
        if (x < 0 || (x % 10 == 0 && x != 0)) return false;

        long long recv = 0;
        while(x > recv){
            recv = recv * 10 + x % 10;
            x /= 10;
        }

        return x == recv || x == recv / 10;
    }
};
```
