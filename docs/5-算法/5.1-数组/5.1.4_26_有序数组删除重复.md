# 有序数组删除重复值

https://leetcode.cn/problems/remove-duplicates-from-sorted-array/


# 示例

# 解法

## 方法1

```cpp
class Solution {
public:
    int removeDuplicates(vector<int>& nums) {

        int slow = 0;
        for (int fast = 1; fast < nums.size();fast++){
            if(nums[slow] != nums[fast]){
                slow++;
                nums[slow] = nums[fast];
            }
        }
        return slow + 1;
    }
};
```
