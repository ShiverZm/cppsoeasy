# 死锁
多个线程/进程互相持有对方需要的资源，并且都在等待对方释放，导致谁也无法继续执行。

四个必要条件（缺一不可）
互斥：资源同一时刻只能被一个线程占用
持有并等待：持有一个资源的同时，等待另一个资源
不可剥夺：资源只能由持有者主动释放
循环等待：存在线程间的环形等待链

破坏任意一个条件，就能避免死锁。

# 死锁建议
常见解决办法
办法	破坏的条件	做法
固定加锁顺序	循环等待	所有线程按统一顺序加锁（最常用，如按地址或编号排序）
一次性加多个锁	持有并等待	C++11 std::lock(m1, m2) 或 C++17 std::scoped_lock lk(m1, m2)，内部用避免死锁的算法
尝试加锁 + 超时	持有并等待 / 不可剥夺	try_lock、timed_mutex::try_lock_for，失败则释放已持有的锁并重试
减小锁粒度/缩短持锁时间	降低概率	不要持锁时调用外部代码、回调、阻塞 I/O
避免嵌套锁	持有并等待	一次只持有一把锁
用无锁结构 / 原子操作	互斥	std::atomic、无锁队列
