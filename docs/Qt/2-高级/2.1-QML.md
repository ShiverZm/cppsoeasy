# 前言

从 Qt 4.7 开始，Qt 引入了一种声明式脚本语言，称为 QML（Qt Meta Language 或者 Qt Modeling Language），作为 C++ 语言的一种替代。而 Qt Quick 就是使用 QML 构建的一套类库。

# qml

```cpp
import QtQuick
import QtQuick.Controls

Window {
    width: 400; height: 300
    visible: true

    Rectangle {
        anchors.centerIn: parent
        width: 120; height: 60
        color: mouse.containsMouse ? "orange" : "steelblue"
        radius: 8

        Text { anchors.centerIn: parent; text: "点我"; color: "white" }

        MouseArea {
            id: mouse
            anchors.fill: parent
            hoverEnabled: true
            onClicked: console.log("clicked")
        }
    }
}
```

QML 的特点:

- 声明式:描述"是什么"而不是"怎么做"
- 属性绑定:width: parent.width / 2 会自动随父元素变化更新
- 内置动画与状态机:做动画、过渡非常方便
- GPU 渲染:基于 Qt Quick Scene Graph,流畅度高,适合触屏和炫酷界面
- 内嵌 JavaScript 处理简单逻辑
