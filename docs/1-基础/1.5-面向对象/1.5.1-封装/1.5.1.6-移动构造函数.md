# 移动构造函数（C++11）

从将亡值（右值）"偷"资源，避免深拷贝。

```cpp
struct Buf {
    int* data;
    size_t n;
    Buf(Buf&& other) noexcept
        : data(other.data), n(other.n) {
        other.data = nullptr;   // 把源对象置于可析构的有效状态
        other.n = 0;
    }
};
Buf b1 = make_buf();            // 临时对象，触发移动
Buf b2 = std::move(b1);         // 显式移动
```

场景： 对象持有堆内存、文件、锁等资源，且经常被返回或放入容器。一定要标 noexcept，否则 vector 扩容时会选择拷贝而不是移动。
