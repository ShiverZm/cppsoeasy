# 拷贝构造函数

用同类型的已有对象创建新对象。

```cpp
struct A {
    A(const A& other);      // 参数必须是引用，否则会无限递归
};
A a1;
A a2(a1);                   // 直接拷贝
A a3 = a1;                  // 拷贝初始化
void f(A a);                // 值传参时调用
A g();                      // 返回值（C++17 前可能触发，之后多被省略）
```

场景： 需要深拷贝时（类里有指针、文件句柄等资源）必须自己写。遵循"三法则"：写了析构、拷贝构造、拷贝赋值中的一个，通常另外两个也要写。
