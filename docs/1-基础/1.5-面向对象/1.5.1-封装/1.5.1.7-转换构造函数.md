# 转换构造函数

单参数（或其余有默认值）的构造函数，允许从其他类型隐式转换。

```cpp
struct Str {
    Str(const char* s);         // const char* -> Str 的隐式转换
};
Str s = "hello";                // 隐式转换

struct Safe {
    explicit Safe(int n);       // 禁止隐式转换
};
// Safe s = 5;                  // 错误
Safe s(5);                      // 正确
```

场景： 类型之间确有自然转换时使用（如 string 从 const char*）。多数情况建议加 explicit，防止意外转换。
