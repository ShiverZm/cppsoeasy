# 非多态特征

定义两个类A和B。 
```cpp
class A { public: void Func() { cout << "A.Func" << endl; } };
class B : public A { public: void Func() { cout << "B.Func" << endl; } }; 

int main(int argc, char** argv) { 
    B b; A* a = &b; 
    b.Func(); a->Func(); 
}
```
最终的输出顺序是：
第一行：B.Func
第二行：A.Func

1. b.Func()调用
当使用b直接调用Func()时，由于b是B类型的对象，会调用B类中定义的Func()函数，输出"B.Func"。

2. a->Func()调用
虽然a指向了B类对象，但因为A类中的Func()函数不是虚函数（没有使用virtual关键字），所以这里发生的是静态绑定，而不是动态绑定。根据指针的静态类型A来决定调用哪个函数，因此会调用A类的Func()函数，输出"A.Func"。
