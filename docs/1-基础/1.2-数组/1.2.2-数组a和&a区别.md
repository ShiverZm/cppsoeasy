# a 和 &a

数组名 `a` 表示首元素，`&a` 表示整个数组。两者地址数值相同，类型和步长不同。

## 对照

以 `int a[10];` 为例。

| 表达式 | 类型 | `+1` 的步长 |
| --- | --- | --- |
| `a` | 多数表达式中退化为 `int*` | `sizeof(int)` |
| `&a[0]` | `int*` | `sizeof(int)` |
| `&a` | `int (*)[10]` | `sizeof(a)`，即 10 个 `int` |

| 表达式 | 结果 |
| --- | --- |
| `sizeof(a)` | 整个数组 |
| `sizeof(&a)` | 一个指针 |
| `sizeof(*a)` | 一个 `int` |

普通变量 `int n;` 里，`n` 是对象，`&n` 的类型是 `int*`。

## 易错点

1. 数组作函数参数时退化成指针。`void f(int a[10])` 中 `a` 的类型是 `int*`，`&a` 的类型是 `int**`。
2. `a` 和 `&a` 打印出来的地址一样，不能据此当成同一类型。
