# 常见数据类型及大小

C++ 标准只规定了基本类型的**最小位宽**和**相对大小**，具体占几个字节由实现决定。下面按现在最常见的 64 位平台来记：Linux / macOS 用 LP64，Windows 用 LLP64。32 位程序一般是 ILP32，`int`、`long`、指针都是 4 字节。

## 基本类型

| 类型 | Linux / macOS（LP64） | Windows（LLP64） | 备注 |
| --- | --- | --- | --- |
| `bool` | 1 | 1 | 标准未规定，主流实现是 1 字节 |
| `char` / `signed char` / `unsigned char` | 1 | 1 | `sizeof(char)` 恒为 1 |
| `short` / `unsigned short` | 2 | 2 | 至少 16 位 |
| `int` / `unsigned int` | 4 | 4 | 至少 16 位，实际几乎都是 32 位 |
| `long` / `unsigned long` | 8 | 4 | 64 位下两边不一样 |
| `long long` / `unsigned long long` | 8 | 8 | 至少 64 位 |
| `float` | 4 | 4 | 一般是 IEEE 754 单精度 |
| `double` | 8 | 8 | 一般是 IEEE 754 双精度 |
| `long double` | 见下 | 8 | 实现差异最大 |
| `wchar_t` | 4 | 2 | Linux / macOS 按 UTF-32，Windows 按 UTF-16 |
| `char8_t` | 1 | 1 | C++20 |
| `char16_t` | 2 | 2 | |
| `char32_t` | 4 | 4 | |

`long double` 要单独记：

- x86-64 上的 GCC / Clang：16 字节，有效精度是 80 位，其余是对齐填充。
- Apple Silicon（arm64）：8 字节，和 `double` 相同。
- MSVC：8 字节，和 `double` 相同。
- 多数 AArch64 Linux：16 字节，IEEE 754 四精度。

有符号和无符号是两套类型，大小、对齐要求相同。`unsigned` 单独出现时就是 `unsigned int`。

## 指针和与地址相关的类型

| 类型 | 32 位 | 64 位 | 备注 |
| --- | --- | --- | --- |
| 对象指针 `T*` | 4 | 8 | 和指向的类型无关，`char*` 和 `double*` 一样大 |
| 函数指针 | 4 | 8 | 个别架构可能更大 |
| `std::nullptr_t` | 实现定义 | 实现定义 | 通常与 `void*` 相同 |
| `size_t` | 4 | 8 | 无符号，`sizeof` 的结果类型 |
| `ptrdiff_t` | 4 | 8 | 有符号，两个指针相减的结果类型 |
| `intptr_t` / `uintptr_t` | 4 | 8 | 足够装下一个指针的整数 |

引用不是对象。`sizeof` 作用在引用或引用类型上时，结果是被引用对象的大小。

## 定宽整数

宽度已经写在名字里，跨平台代码优先用 `<cstdint>`：

| 类型 | 大小 |
| --- | --- |
| `int8_t` / `uint8_t` | 1 |
| `int16_t` / `uint16_t` | 2 |
| `int32_t` / `uint32_t` | 4 |
| `int64_t` / `uint64_t` | 8 |

`intN_t` 是可选的，平台没有正好 N 位的整数时可以不提供。`int_leastN_t`、`int_fastN_t` 一定存在，只保证不少于 N 位。

## long long 和 unsigned long long

两者都至少 64 位。32 位和 64 位的主流平台上都是正好 64 位、8 字节，对齐一般也是 8。`long long`、`long long int`、`signed long long` 是同一类型；`unsigned long long` 和 `unsigned long long int` 是同一类型。

在 `sizeof == 8` 时，范围是：

| | `long long` | `unsigned long long` |
| --- | --- | --- |
| 最小值 | -9223372036854775808（`-2^63`，`LLONG_MIN`） | 0 |
| 最大值 | 9223372036854775807（`2^63 - 1`，`LLONG_MAX`） | 18446744073709551615（`2^64 - 1`，`ULLONG_MAX`） |
| 字面量后缀 | `42LL` | `42ULL` |
| 溢出 | 有符号溢出是未定义行为 | 按 `2^64` 回绕，结果有定义 |
| 右移 | C++20 起，负数右移是向负无穷取整 | 高位补 0 |
| `printf` | `%lld` | `%llu` |

宏在 `<climits>` 里。也可以用 `std::numeric_limits<long long>::min()` / `max()`，头文件是 `<limits>`。`iostream` 直接输出这两个类型，不用写格式符。

和定宽类型的关系要分开记大小和类型名：

- 常见平台上 `int64_t`、`uint64_t` 都是 64 位，和它们一样大。
- 类型名跟平台走。Linux（glibc，LP64）上 `int64_t` 是 `long`，`uint64_t` 是 `unsigned long`。macOS 和 Windows 上 `int64_t` 是 `long long`，`uint64_t` 是 `unsigned long long`。macOS 上 `long` 也是 8 字节，但和 `long long` 是两个类型。
- 因此 `void f(long)` 和 `void f(long long)` 同时存在时，传入 `int64_t` 在 Linux 上匹配 `f(long)`，在 macOS 和 Windows 上匹配 `f(long long)`。`printf` 同样：Linux 用 `%ld`，macOS 和 Windows 用 `%lld`。老的 MSVC 还认 `%I64d`、`%I64u`。可移植写法是 `<cinttypes>` 的 `PRId64`、`PRIu64`。

字面量按“第一个放得下的类型”来定：

- 十进制无后缀依次尝试 `int`、`long`、`long long`。比 `LLONG_MAX` 还大时，标准认为程序非法，应写成 `...ULL`。Clang 会警告，并把这个十进制数解释成无符号。
- 十六进制还会继续尝试无符号类型。`0x8000000000000000` 是 `2^63`，放不进有符号 64 位。LP64（Linux / macOS）上它的类型是 `unsigned long`；Windows 上 `unsigned long` 只有 32 位，类型就是 `unsigned long long`。
- `-9223372036854775808LL` 会先解析正数再取负，这个正数放不进 `long long`。最小值写成 `LLONG_MIN`。

两边都是整数时，会先转换成同一个类型再运算。表达式里有 `unsigned long long`，另一边的整数等级不高于它，另一边就转成 `unsigned long long`。负数转过去之后变成一个很大的正数：

```cpp
long long a = -1;
unsigned long long b = 1;
bool less = a < b; // a 变成 2^64 - 1，比较结果是 false
```

选用时看值会不会为负：差值、偏移用 `long long`；位掩码、哈希、模 `2^64` 的计数用 `unsigned long long`。同一个表达式里把它们混在一起，负数会按上面的规则变成大正数。

## 标准保证的关系

- `sizeof(char) == 1`，并且 `char` 至少 8 位（`CHAR_BIT >= 8`）。C++ 里的“字节”就是 `char` 的大小，常见平台上是 8 位。
- `sizeof(char) <= sizeof(short) <= sizeof(int) <= sizeof(long) <= sizeof(long long)`
- `sizeof(float) <= sizeof(double) <= sizeof(long double)`
- 同一整数的有符号、无符号版本大小相同。
- 操作数是类型或完整对象时，`sizeof` 在编译期求值。数组做 `sizeof` 的操作数时不会退化成指针，见 [sizeof 和 strlen](../1.3-字符串/1.3.1-sizeof和strlen.md)。

## 面试里要记住的点

1. `float` 是 4 字节，`double` 是 8 字节。
2. 64 位下 `long` 跟着数据模型走：Windows（LLP64）是 4，Linux / macOS（LP64）是 8。要表示 64 位整数，用 `int64_t` 或 `long long`。`long long` 和 `unsigned long long` 在 32 位、64 位上都是 8 字节，差别在符号和 `2^64` 的取值范围。
3. 同一平台上对象指针大小相同。64 位是 8，32 位是 4。
4. 函数参数里的数组会退化成指针。`void f(int a[100])` 中 `sizeof(a)` 是指针大小。
5. 空类大小是 1，这样不同对象才能有不同地址。带虚函数的类至少还要放一个虚表指针，64 位上通常再加 8，见 [空类的大小](../1.5-面向对象/1.5.11-空类的大小和成员函数.md) 和 [虚函数表](../1.5-面向对象/1.5.7-虚函数表.md)。
6. 枚举的大小等于底层类型。有作用域枚举未指定时默认是 `int`；无作用域枚举只要能放下全部枚举值，具体类型由实现决定，常见也是 4 字节。
7. `bool` 一般占 1 字节。`std::vector<bool>` 是按位打包的特化，元素不是普通 `bool` 对象。
8. 结构体要算对齐填充，大小一般大于成员大小之和。共用体取能放下最大成员、并且满足对齐的大小，见 [共用体](../1.1-基础/1.1.9-共用体.md)。

## 自己确认

```cpp
#include <iostream>
#include <cstddef>

int main() {
    std::cout << sizeof(int) << '\n';
    std::cout << sizeof(long) << '\n';
    std::cout << sizeof(long long) << '\n';
    std::cout << sizeof(unsigned long long) << '\n';
    std::cout << sizeof(float) << '\n';
    std::cout << sizeof(double) << '\n';
    std::cout << sizeof(long double) << '\n';
    std::cout << sizeof(void*) << '\n';
    std::cout << sizeof(std::size_t) << '\n';
}
```
