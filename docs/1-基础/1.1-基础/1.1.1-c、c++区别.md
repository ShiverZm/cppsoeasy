# C 和 C++ 的区别

C++ 兼容 C 的面向过程写法，并支持面向对象、泛型和模板元编程。

## 对照

| 对比项 | C | C++ |
| --- | --- | --- |
| 范式 | 面向过程 | 面向过程、面向对象、泛型、模板元编程 |
| 堆内存 | `malloc` / `free` | `new` / `delete` |
| 引用 | 无 | 有 |
| 类 | 无 | 有 |
| 函数重载 | 无 | 有 |

## 易错点

1. 同一块内存用 `new` 分配就用 `delete` 释放，用 `malloc` 分配就用 `free` 释放。
2. C++ 源文件可以只写函数和结构体，按面向过程编译通过。
